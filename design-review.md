# Example: using the skill during a website review

## Prompt

Read and follow `SKILL.md`. Review this website as a product designer.

1. Inspect the actual pages and current implementation.
2. Identify visual clichés that appear without a clear product-specific reason.
3. Check typography, color, layout, responsive behavior, accessibility, and interface states.
4. Do not replace the existing design wholesale just to make it look different.
5. Propose the smallest set of changes that meaningfully improves the product.
6. Do not invent testimonials, metrics, or functionality.
7. Report what you inspected and what remains unverified.

## Expected outcome

A grounded review tied to the actual product and implementation, not a generic list of design trends.
